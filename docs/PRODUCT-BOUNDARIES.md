# 产品边界

这份文档说明 Cognatlas 是什么、不是什么，以及发布时对外承诺到什么程度。
它和 README 的区别：README 讲怎么用，本文讲边界与责任。

## 平台矩阵

| 平台 | 状态 | 验证程度 | 说明 |
|---|---|---|---|
| Linux x64 | 主要支持 | Fedora 44 实机；核心/CLI/UI 回归 | 需要系统 Git + Python 3 |
| Windows x64 | 预览 | Wine 11.22 实测 W1–W8 | 随包 Python 3.12.8 + MinGit 2.56.1；未在真实 Windows 长期验证 |
| macOS | 不支持 | 未构建、未测试 | 没有 .app、没有签名/公证 |
| Linux ARM64 | 不支持 | 未构建 | 发布包只有 x64 |
| Windows ARM64 | 不支持 | 未构建 | 发布包只有 x64 |

Windows 预览的含义：主要路径已实测，但不承诺所有 Windows 版本、杀软、
企业策略、中文输入法组合都与 Wine 结果一致。遇到问题按 Issue 模板报告。

## 非目标

以下不是当前版本要做的事，不要按这些预期验收：

- 多用户、团队权限、审计后台。
- 云同步、账号体系、跨设备漫游。
- 移动端、macOS 客户端、Web 版。
- WYSIWYG 编辑器；编辑器是 Markdown + 行内渲染，不是富文本。
- 插件市场、插件签名、插件权限审批。
- 自动更新、增量升级、崩溃上报。
- 把任意现有文件夹改造成 OKF 库的迁移器；自动建库只对空目录生效。

## 七条硬边界

1. **空目录可建库，非空目录不改写。** 选择一个空目录（或只有 .git 的目录）
   首次打开时，客户端会生成 .okf/okf_commit.py、okf、config.yaml、health.yaml
   和示例检查器，并做一次初始提交。非空且没有 .okf 的目录只做 git init，
   可以阅读和编辑，但不能提交、跑健康检查或加载插件，保存返回 NO-OKF；
   不会覆盖或改造用户已有文件。
2. **令牌不是安全边界。** 令牌用于身份、审计与吊销，防止误用与匿名提交；
   它不隔离同机同用户的进程。能读你用户目录的进程本来就能读知识库。
3. **插件默认信任。** 声明式插件只声明渲染块；带 client.js 的插件在 sandbox iframe
   中运行，拿不到 window.kb、Node 或 ipcRenderer，但它仍是你主动放进知识库的代码。
   不要安装来源不明的插件；可用 config.json 的 plugins.client_enabled=false
   或 KB_NO_PLUGIN_CLIENT=1 全局关闭 client 插件。
4. **未签名。** Windows exe 没有代码签名，SmartScreen 会提示未知发布者；
   Linux 包没有发行版仓库签名。请从本项目 Release 下载并核对 SHA256SUMS。
5. **无自动更新。** 升级方式是解压新版本覆盖程序目录；用户数据在配置目录，
   不会被覆盖，但也没有迁移器。升级前自行备份知识库。
6. **本地单用户。** 没有账号、没有云、没有遥测。客户端只访问本机
   127.0.0.1:18812 和你主动打开的外链。详见 docs/PRIVACY.md。
7. **许可证是 Apache-2.0，不是公有领域。** 允许商业使用、修改、再分发，
   但必须保留 LICENSE/NOTICE 与第三方声明；Apache-2.0 不授予项目名称、
   图标或商标的使用权，不要暗示官方背书。

## 数据与责任

- 知识库是你的普通文件夹，客户端不拥有它；卸载客户端不会删除知识库。
- 客户端会写配置、令牌、窗口状态、条目 tag、外链快照到用户配置目录；
  删除位置见 docs/PRIVACY.md。
- 保存失败时以状态栏错误码为准；LINT-REJECT 不会改写文件。
- 没有备份服务。git 历史是知识库自身的版本记录，不是异地备份。

## 发布渠道与版本

- 源码：公开 Git 仓库（Apache-2.0）。
- 二进制：GitHub Release asset；Windows zip 约 162 MB，超过 git 单文件限制，
  因此不进入源码历史。
- 版本：0.1.x 为 preview；接口与配置键可能在小版本内调整，破坏性变更写进
  CHANGELOG.md。
- 支持策略：只对最新 preview 版本接受问题报告；旧版本不承诺修复。
