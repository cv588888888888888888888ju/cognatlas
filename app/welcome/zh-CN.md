# 欢迎使用 Cognatlas

这是一篇内置介绍，不属于你的知识库，随时可以从命令面板（Ctrl+P →「打开介绍文档」）重新打开。

## 这是什么

Cognatlas 是一个本地优先的 AI 知识库客户端：直接读写一个 git 仓库里的 .md 文件，遵循 OKF 规范（frontmatter + 三必填），所有内容都在你自己的磁盘上。

## 界面分区

- **左侧栏**：文件树（点开目录、点文件打开文档）、搜索框、反链列表。
- **顶部标签条**：打开过的文档，点 × 关闭；Ctrl+W 关闭当前。
- **属性块**：frontmatter 渲染成键值表，tags 是紫色标签；点值可编辑，回车保存并入库。
- **正文**：Live Preview —— 标题、粗斜体、行内代码、表格、图片、代码高亮；光标所在行显示源码，方便改。
- **状态栏**：当前字数、反链条数、保存状态。

## 常用快捷键

| 快捷键 | 作用 |
|---|---|
| Ctrl+N | 新建笔记（写进 00-收件箱） |
| Ctrl+O | 快速切换文档 |
| Ctrl+W | 关闭当前标签 |
| Ctrl+S | 立即保存并入库（平时编辑完 1.2 秒会自动保存） |
| Ctrl+P | 命令面板 |
| Ctrl+Shift+F | 全库检索（过期文档照常召回并带警告） |
| [[ | 输入两个方括号触发文档链接补全 |
| # | 标签补全 |

## 链接的三种用法

- **悬浮**：预览标题、路径、摘要与反链数。
- **左键**：在当前标签打开内部链接；外部链接在内置浏览器打开。
- **中键 / Ctrl+左键**：新开一个窗口（内部链接）；外部链接交给系统浏览器。

## 内置浏览器与外链快照

外部链接默认在内置浏览器里打开，登录状态会保留（独立分区，重启不丢）。页面加载完会自动存一份快照（同一地址 6 小时内只自动存一次），也可以点工具栏「快照」手动存；「历史」按时间列出该地址的所有版本，源站打不开时仍能读本地存档。

## 数据在哪

- 知识库：由启动时的 KB_ROOT 指定（默认是你的知识库目录），每个改动都走 git 提交。
- 外链快照：`~/.config/cognatlas/links/`（HTML、正文、截图）。
- 窗口尺寸与会话：Electron userData 目录下的 `window-state.json` 与浏览器 localStorage。

## 切换到英文

命令面板（Ctrl+P）→「Switch intro language」，或本页顶部的语言按钮。
