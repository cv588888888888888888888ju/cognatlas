## 30 秒上手

- 左边是文件树，点一篇打开；顶部是标签条，Ctrl+W 关闭当前。
- 正文直接编辑，停手 1.2 秒自动保存并做一次 git 提交；Ctrl+S 是立刻保存。
- 属性块（frontmatter）在正文上方：点值可编辑，标签是紫色小胶囊。
- Ctrl+P 命令面板；Ctrl+Shift+F 全库检索；Ctrl+F 当前文档查找。

## 界面分区

- **左侧栏**：文件树（搜索框可过滤）、反链列表。
- **顶部检索栏**：横贯窗口，支持 `tag:` / `path:` / `type:` / `status:` / `-tag:` 语法，↑↓ 选择、Enter 打开、Esc 收起。
- **标签条**：打开过的文档；中键或 Ctrl+左键点链接可开新窗口。
- **属性块**：frontmatter 的键值表；悬停展开，点「＋ 添加属性」补字段。
- **正文**：Live Preview —— 标题、粗斜体、行内代码、表格、图片、代码高亮；光标所在行显示源码。
- **状态栏**：字数、反链数、保存状态。

## 常用快捷键

| 快捷键 | 作用 |
|---|---|
| Ctrl+N | 新建笔记（写进 00-收件箱） |
| Ctrl+O | 快速切换文档 |
| Ctrl+W | 关闭当前标签 |
| Ctrl+S | 立即保存并入库 |
| Ctrl+P | 命令面板 |
| Ctrl+Shift+F | 全库检索 |
| Ctrl+F | 当前文档内查找 |
| `[[` | 文档链接补全 |
| `#` | 标签补全 |

## 链接的三种用法

- **悬浮**：预览标题、路径、摘要与反链数。
- **左键**：当前标签打开内部链接；外部链接进内置浏览器。
- **中键 / Ctrl+左键**：新开窗口；外部链接交给系统浏览器。

## 图片

正文里可以直接显示知识库内的图片：写 `![](相对路径)`，路径相对当前文档，或以 `/` 开头表示知识库根；PNG/JPEG/WebP/GIF 都会内联渲染。当前版本还没有「粘贴截图 / 拖入文件 / 命令面板插入图片」的自动落盘，先把图片放进 `_assets/`，再在正文引用。

## 数据在哪

- 知识库：由启动时的 KB_ROOT 或客户端设置指定，每个改动都走 git 提交。
- 外链快照：`~/.config/cognatlas/links/`（HTML、正文、截图）。
- 会话与窗口状态：Electron userData 目录。

## 切换语言

命令面板（Ctrl+P）→「切换介绍语言」，或本页顶部的语言按钮。切换会停留在当前这篇。
